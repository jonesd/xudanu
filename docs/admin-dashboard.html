Overview

The Admin Dashboard provides a single-screen view of the Xudanu server's operational state. It auto-refreshes every 5 seconds, highlighting anything unusual so operators can spot problems before they become critical.

What it monitors: System health (status, checkpoint recency), resource counts (works, links, sessions, editions), and automated health checks for common failure modes.

Accessing the Dashboard

Click the small "Admin" button in the bottom-right corner of any page. The dashboard opens as a full-screen overlay. Click "Close" or press the button again to return to the normal interface.

Auto-refresh: The dashboard polls /health every 5 seconds. The last update time is shown in the header. Click "Refresh" for an immediate update.

Critical Gaps & Future Work

Known gaps in monitoring coverage:
  • Data integrity: No automated check that all chunks are readable and match hashes
  • Backup verification: Backups exist but no automated restore-test
  • Memory monitoring: No memory usage reporting
  • Disk space: No disk space monitoring (full disk causes checkpoint failure)
  • Connection quality: No WebSocket disconnect/latency tracking
  • Session details: No per-session view (IP, work, duration)
  • Security events: No real-time view of chained security log
  • Rate limiter status: No view of blocked IPs or notification counts
