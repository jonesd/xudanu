# Xudanu in pictures

A one-page visual tour of the live UI. Every screenshot below is the real
application running against seeded demo corpora — no mockups. The same
images power the [README](https://github.com/jonesd/xudanu#readme); this
page gathers them (and their folder-mates) for the docs site.

A note on freshness: some shots predate the classic-first landing
redesign (v1.22.x). A refresh session is planned — see
[screenshot-session.md](screenshot-session.md). Corrections to any
caption are welcome and will be attributed.

## Transclusion: windows, not copies

The three-beat story — include a passage by reference, edit the
source, watch the inclusion update.

**1. The included view** — the passage appears inside its new home.

![Source edited](screenshots/showcase/10-transclusion-source-edited.png)

**3. Updated by reference** — the inclusion reflects the edit. No
