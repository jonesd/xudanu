LLM Integration

Xudanu's LLM features: the machine as reader-critic, narrator, and categorizer — participating in the same hypertext as human readers, subject to the same social filtering.

Heritage. Miller, “The Open Society and Its Media” (1995): “All readers of the system are potential authors.” The LLM is a reader. It reads, it connects, it participates. The community decides whether its contributions are worth reading.

The design principle

No special treatment. The LLM's arguments compete in the same marketplace of ideas as human arguments. Its connections carry the same typed vocabulary, the same span-level precision, the same bidirectional visibility. The only difference: a human confirms before any link enters the graph, and the provenance chain stamps the model identifier.

The LLM never creates links directly. It proposes them; a human decides. Confirmed proposals enter the same argument chains as human connections, carry model-ID provenance, and compete for endorsements identically.

The features

FR-86

Suggest Connections

The LLM reads a work and its connected works, then proposes typed connections (Disagreements, References, Comments) a critical reader would make. Proposals include span, type, reasoning, and confidence. Human confirms before any link is created.

shipped

Diff Narration

When a work is revised, the LLM generates a natural-language summary of what changed. Powers Miller's differential reading: read only the difference since your last look.

shipped

Auto-Tag

The LLM categorizes a work into your existing concept taxonomy (or proposes new concepts). Helps organize large libraries without manual filing.

shipped

Find Related

The LLM identifies which existing works are semantically related to a new work, suggesting connections the reader might have missed.

Local setup (macOS)

# 1. Install Ollama
brew install ollama

# 2. Start the server (runs on port 11434)
ollama serve

# 3. Pull a model (one-time download)
ollama pull qwen2.5:1.5b     # fast, good for proposals
ollama pull llama3.1          # larger, better reasoning

# 4. Start xudanu-server with the LLM enabled
OLLAMA_BASE_URL=http://localhost:11434 \
OLLAMA_MODEL=qwen2.5:1.5b \
xudanu-server run 127.0.0.1:8080 data --allow-loopback \
  --allowed-origin http://localhost:5173 --csrf-token

When the server starts, the log confirms: llm: Ollama enabled (model=qwen2.5:1.5b at http://localhost:11434)

If no LLM is configured, the features gracefully degrade: the "Suggest connections" button returns an explanatory message, auto-tag returns an empty list, narration returns a placeholder.

The FR-86 flow: propose → confirm → connect

1
Trigger. The reader clicks "Suggest connections" on any work. The client sends llm_propose_connections (wire op 0x0f2a).
2
Context. The server loads the work's full text + the texts of up to 5 connected works (via the link graph). No manual feeding.
3
Prompt. The server builds a critical-reader prompt: the document, its connected works, the five connection types with definitions, and instructions to identify claimable passages. The LLM responds with structured JSON proposals.
4
Resolve. The server parses the proposals, verifies each excerpt appears verbatim in the text, and resolves the span. Invalid proposals are silently dropped.
5
Present. The client renders proposals as authoring cards: the passage (underlined), the proposed type, the reasoning, the confidence. The human can confirm, edit (adjust span or type), or reject.
6
Connect. Confirmed proposals are created via the standard link_create op. The link carries the LLM's model identifier in its provenance chain. It enters the argument chain, the Beams view, and the endorsement marketplace identically to human connections.

What the research says

From the 2024–2026 literature:
  • LLMs are better at identifying weaknesses than suggesting fixes (Saqr 2025) — Disagreements will be their strongest contribution
  • LLM arguments are linguistically different from human ones (Dönmez 2025) — more formal, less personal. The system does not disguise this; transparency is the design
  • Hybrid LLM-symbolic outperforms pure LLM (Vasileiou 2026) — the LLM proposes, the formal link vocabulary validates
  • Confidence scores are unreliable (Sanayei 2025) — the human-confirmation step is not optional
  • Measured, evidence-focused style gets more endorsements than aggressive style (Verma 2025) — the prompt asks for restraint
