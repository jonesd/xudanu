About this documentation

Nothing on this site is Project Xanadu documentation.

The Udanax Gold source release (Copyright 1979–1999 Udanax.com, license preserved as LICENSE-udanax-gold.txt in the repository) contained source code and its license — and no design documentation. None is known to exist publicly.

Every document that explains the Gold model on this site and in original-code/xanadugold/src-rust/docs/ is an interpretation, written in 2026 by the xudanu project from reading the released code. Where the source is ambiguous, the reading is ours. The code itself is the primary source and the final authority.

The docs/dev/ series (FR-nnn design specs) is a different genre: the project’s own engineering records for new work, not descriptions of Udanax Gold.

If you know of original Project Xanadu or Udanax design documentation in any archive, we would be very glad to hear of it — that material is exactly what this project has never had.
