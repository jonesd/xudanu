# Session Log: 2026-04-21

## What we did

### 1. Evaluated Yrs and decided to adopt it

We reviewed the `yrs` crate (v0.25.0, MIT license, by Kevin Jahns/Horusiath) — the official Rust port of Yjs. After analyzing the complexity of our broken custom CRDT engine (21 test failures, fundamental algorithmic issues with concurrent deletes and out-of-order delivery), we decided to replace it entirely with yrs rather than continue debugging.

Key findings:
- yrs is mature, WASM-compatible, has sync protocol and awareness built in
- Its observer system and Protocol trait provide extension points for our signing layer
- MIT license allows forking if needed

### 3. Rewrote CRDT engine (Phase 1)

Replaced 774 lines of broken `sequence.rs` + 46 lines of `merge.rs` with a ~380 line `doc.rs` wrapper around `yrs::Doc`.

Key bugs we hit and fixed:
- **Shared client IDs**: Initially derived yrs client IDs from Ed25519 public keys. This caused state corruption because yrs requires unique client IDs per active replica. Fixed by using `yrs::Doc::new()` with random IDs.
- **Branch cloning**: `yrs::Doc::clone()` shares internal `Arc<DocInner>`, so branch edits affected the main doc. Fixed by deep-copying via serialize/deserialize.
- **Double-counting in sync**: `integrate_change()` didn't update `last_committed_sv`, so subsequent commits re-included already-integrated changes. Fixed by updating the state vector after integration.
- **Author attribution**: yrs's `diff()` merges adjacent blocks from different clients if they have the same formatting. Fixed by attaching `__author` formatting attribute to every insertion, forcing diff to separate blocks by author.

### 4. Added signing integration (Phase 2)

Created `SignedDocument` — a wrapper that ties `Document` + `Signer` + key registry together:
- `commit_signed_change()`: signs every outgoing change with Ed25519
- `integrate_signed_change()`: verifies signature before applying to yrs
- `register_author()`: stores public key for verification
- 4 error modes: missing signature, invalid signature, unknown author, author revoked

7 new tests covering happy path, tampering, forgery, and convergence.
