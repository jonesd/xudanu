The xudanu Namespace

Vocabulary for xudanu provenance export in W3C PROV-JSON: cryptographically signed, per-span authorship for collaborative hypertext documents (transclusion-aware). Terms are used as PROV extensions — qualified names in the xudanu: prefix — inside documents serialized per the PROV-JSON specification.

Namespace URI: https://dgjones.info/ns/xudanu/ · see also project documentation.

Identifier conventions

Entity, agent, and activity identifiers are QNames in this namespace with structured local names:

xudanu:span_{work}_{start}_{end}a span entity (work id, char range)
xudanu:agent_{key16}an author agent (first 16 hex of verifying key)
xudanu:server_{id8}a server agent
xudanu:activity_{work}_{ts}an edit activity
xudanu:federation_consensus_{ts}the federation witnessing bundle
Maintained by the xudanu project (Apache-2.0). Terms may evolve; new terms will only be added, never repurposed. Generated to accompany the PROV-JSON export of the xudanu provenance & attestation subsystem.
