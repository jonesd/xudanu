The Ladder of Links

From the web you know to the system you don't — ten kinds of connection, each one running.

1The one-way link (what you already know)

You already know this one. A hyperlink on a webpage:

any-webpage.html
For more information, click here.

One direction. Points at a whole page. The target page has no idea who points at it. If the source page disappears, the link breaks. That's the web.

One direction. B doesn't know A exists.

2The bidirectional link (both ends see it)

Now imagine the same link, but both documents know about it. Document B can see who connected to it, without anyone editing Document B.

Both ends see the same connection. Nobody edited Document B.

"Who disagrees with me?" is a query, not a research project.

3The typed link (connections carry meaning)

On the web, all links are the same — a hyperlink is a hyperlink. Here, each link has a type that says what kind of relationship it is. The type determines the colour of the underline.

Here's a passage that two different people connected to, in different ways:

A passage being connected to
This claim about transclusion needs more evidence.

The blue underline means one person made a Comment. Here's the same passage with a different kind of connection:

Same passage, different connection
This claim about transclusion needs more evidence.

The red underline means someone Disagrees with this passage specifically — not the whole document, this exact sentence.

There are six built-in types, each with its own colour:

All six types on one sentence
A comment that doubts, a reference that grounds, a disagreement that pushes back, a quotation that borrows, a see-also that gestures sideways, and a web link that leaves the system.
Comment — "this passage makes me think..."
Reference — "this is supported by..."
Disagreement — "this specific claim is wrong because..."
Quotation — "this passage quotes..."
See Also — "these belong in one conversation"
Web Link — "this points outward"

"Show me only the disagreements" — filtering by relationship type.

4The span-level link (passages, not pages)

Web links point at whole pages. Here, links point at specific passages — a sentence, a phrase, even a single word.

A document
The evidence suggests that transclusion is the correct mechanism for verifiable quotation in distributed systems, though some disagree with the overhead claim.

Two different links on two different passages in the same document. The red one disagrees with the mechanism claim. The amber one flags the overhead debate as a "see also." Each targets an exact span.

The link survives edits. If someone inserts a paragraph above the red-underlined sentence, the address tracks the content — not the position. The link still points at the same sentence.

Cite the exact sentence you disagree with, not "somewhere in that document."

5The multi-ended link (one connection, many ends)

A regular link has two ends: origin and destination. But here, a single link can have three, four, five ends. Not a chain of links — one connection with multiple endpoints.

One passage, three ends — one connection, not three links.

Here's what it looks like in the actual rendering — one word carrying five connections:

The Junction Word
One word can be a station. The word everywhere below is the meeting point of five departing connections — five colours, five destinations, one passage.

"These three documents, connected at this one point" — a junction, not a list.

6The gathered end-set (many passages, one voice)

This is the one nobody has seen before. A gathered end-set is multiple passages — from different documents — acting as one end of a connection. Not three separate links. One connection, with one end made of three passages.

The three passages aren't three separate links — they're one end of one connection, gathered. The chips ("1 of 3") are the visual indicator. Together they fill one blank in the connection.

This is not a list, not a tag, not a folder. It's a structural unit. If you add a fourth claim, the gathering grows. If you remove one, it shrinks. The connection stays. The evidence is the unit, not any single passage.

7The link-about-link (commentary on a connection)

You can comment on a connection itself — not on either document, but on the relationship between them. The commentary attaches to the link.

Document A
This passage disagrees with Document B.
Document B
The disputed passage.
Commentary on this connection
Note: this disagreement is about methodology, not the conclusion — both authors agree on the finding.

Meta-discussion: "the connection between these two ideas is itself problematic."

8The transclusion (a live window, not a copy)

Not a link. Not a copy. A live window onto text that lives in another document. Edit the source and this updates. The window carries the source's identity.

A document containing a transclusion
The evidence suggests the following: source doctransclusion is inclusion by reference, preserving the identity of the original passage which is why this matters for verifiable quotation.

The dashed border means "this text lives elsewhere." If the source document is edited, the window updates. If 1,000 documents quote the same passage, it's stored once and referenced 999 times.

Quoting without copying. Identity preserved. See the Live Window in the Gallery.

9The trail (a curated path)

A sequence of documents, curated as a reading path. Not a link between two things — a path through many. Bush's associative trails, made structural.

The Curator's Tour

2. The Spectrum Sentence — six types at once
3. The Junction Word — five ends
4. The Rebuttal Constellation — gathering
5. The Live Window — transclusion

A guided tour, a curriculum, an argument that builds across documents.

10The exhibition (membership by connection)

A group of works defined by a gathers link from a cover document. Not a folder, not a tag — membership by connection. Crossing the boundary is indicated to the reader, never a barrier.

The Gallery of Unusual Connections
Wing I · Wing II · Wing III — three exhibitions, each defined by a gathers link from the cover to each member work.

Curated collections, thematic groupings — the exhibition is itself a work.
