# Security Policy

## Reporting a Vulnerability

**Do not report security vulnerabilities through public GitHub issues.**

Instead, use GitHub's private vulnerability reporting:

1. Go to [Security Advisories](https://github.com/jonesd/xudanu/security/advisories/new)
2. Click **Report a vulnerability**
3. Fill in the details

Alternatively, email **david@dgjones.info** with the subject line `[xudanu security]`.

## Response Timeline

- **Acknowledgement**: within 48 hours
- **Triage and assessment**: within 5 business days
- **Fix target**: within 7 days for critical, 14 days for high severity

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest release | Yes |
| Development branches | No |

## Disclosure Policy

We ask that you:

- Give us reasonable time to fix the issue before public disclosure
- Do not access or modify other users' data
- Report in good faith

We will:

- Credit you in the advisory (unless you prefer to remain anonymous)
- Keep you informed of progress toward a fix
